# 🌱 WasteWise
# Smart Waste Management for Smarter Campuses

*Segregate Smart. Dispose Right. Keep India Clean.*

WasteWise is a smart campus waste-management and sanitation platform designed to help educational institutions manage **waste segregation, disposal, collection, and sanitation** through a single digital system.

The platform connects **students, sanitation staff, and campus administrators** to create a more efficient, transparent, and sustainable waste-management ecosystem.

# Our Solution

WasteWise transforms traditional campus waste management into a **data-driven smart campus system**.

Instead of relying only on manual monitoring, students and staff can report waste and sanitation problems through the platform, while administrators can monitor bins, manage collection, assign sanitation tasks, and analyze campus-wide waste data.

### The complete workflow:

**Student identifies problem**  
↓  
**Reports waste/sanitation issue**  
↓  
**Waste is classified / issue is categorized**  
↓  
**Administrator receives the report**  
↓  
**Collection or sanitation staff is assigned**  
↓  
**Issue is resolved**  
↓  
**Data contributes to campus analytics**

# Objectives

- Improve waste segregation in educational institutions
- Reduce overflowing and improperly used waste bins
- Improve waste collection efficiency
- Digitize sanitation complaints
- Encourage students to participate in responsible waste disposal
- Provide administrators with real-time visibility of campus waste management
- Generate useful data for better resource conservation
- Create a scalable system that can be adapted to different campuses

#  Key Features

##  Student Dashboard

Students can:

- Report overflowing bins
- Report incorrect waste segregation
- Report open garbage dumping
- Report sanitation problems
- Upload photographs as evidence
- Select the location of an issue
- Track submitted complaints
- Find nearby waste bins
- Learn proper waste segregation
- Earn WasteWise points
- Participate in campus cleanliness activities

## 🗑️ Smart Bin Monitoring

Administrators can monitor campus waste bins through a centralized dashboard.

Each bin contains information such as:

- Bin ID
- Location
- Waste category
- Fill level
- Last collection time
- Current status

### Bin Status

🟢 **Normal**

🟡 **Almost Full**

🔴 **Collection Required**

The prototype uses simulated bin data, while the architecture is designed to support future integration with IoT-based sensors.
